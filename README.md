# Password Security Analyzer

Password Security Analyzer written in Python as a learning project while studying Python and DevSecOps

## Features
    - checks password lenght
    - checks uppercase letters
    - checks lowercase letters
    - checks digits
    - checks special characters
    - Detects common weak patterns
    - Detects repeated characters 
    - Rates password as Weak, Medium and Strong 

## Example 1

    Input:

    QwErTy$!0023
    
    Output:

    your password is weak because it contains easy-to-guess character combinations

## Example 2

    Input:

    L$01lX00ddXD

    Output:

    Your password is strong
